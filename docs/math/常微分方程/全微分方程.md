## 形式

$$
M(x,y)dx+N(x,y)dy = 0 \ (M^{2}+N^{2}\neq 0)
$$

对于二元函数$u(x,y)$，其微分具有形式

$$
du(x,y) = \frac{ \partial u }{ \partial x } dx +\frac{ \partial u }{ \partial y } dy
$$

若是全微分方程，那么$i.e. \exists u(x,y),s.t.$

$$
\frac{ \partial u }{ \partial x }  = M(x,y)且\frac{ \partial u }{ \partial x } =N(x,y)
$$

此时满足

$$
\frac{ \partial   }{ \partial y } \left( \frac{ \partial u }{ \partial x }  \right) = \frac{ \partial M }{ \partial y } = \frac{ \partial   }{ \partial x } \left( \frac{ \partial u }{ \partial y }  \right) =\frac{ \partial N }{ \partial x }
$$

!!! example
	
	$$
	(1+xy^{2})dx+(1+x^{2}y) = 0
	$$
	
	判断为全微分方程
	
	$$
	\frac{ \partial M }{ \partial y } =\frac{ \partial N }{ \partial x }  = 2xy
	$$
	
	进行求解
	
	$$
	\begin{gathered}
	\frac{ \partial u }{ \partial x } = M =1+xy^{2} \\
	\implies u(x,y) =x+\frac{1}{2}x^{2}y^{2}+\psi(y) \\
	\frac{ \partial u }{ \partial y }  = N =1+x^{2}y \quad yx^{2}+\psi ^{\prime}(y) =1+yx^{2}\implies \psi ^{\prime}(y) = 1\\
	\implies u(x,y) = x+y+\frac{1}{2}x^{2}y^{2}\\
	\implies x+y+\frac{1}{2}x^{2}y^{2} =C\\
	\end{gathered}
	$$
	


## 积分因子
### 情况
当有如下情况时候，需要使用积分因子

$$
若\frac{ \partial M }{ \partial y } \neq \frac{ \partial N }{ \partial x } \overset{\mu \neq 0}{\implies} \frac{ \partial \mu M }{ \partial y } =\frac{ \partial \mu N }{ \partial x }
$$

得到

$$
\frac{ \partial \mu }{ \partial y } M+\mu \frac{ \partial M }{ \partial y } =\frac{ \partial \mu }{ \partial x } N+\mu \frac{ \partial N }{ \partial x } 
$$

若$\mu$与y无关，则$\mu\equiv \mu(x)$


$$
\frac{\frac{ \partial M }{ \partial y } -\frac{ \partial N }{ \partial x }}{x} \equiv \phi(x)=\frac{1}{\mu} \frac{d\mu}{dx}
$$

若$\mu\equiv \mu(y)$，有


$$
\frac{\left( \frac{ \partial M }{ \partial y } -\frac{ \partial N }{ \partial x }  \right)}{M} \equiv \Phi(y)=\frac{1}{\mu} \frac{d\mu}{dy}
$$

!!! example
	
	$$
	ydx+(y^{2}-2x) dy = 0
	$$
	
	第一步：积分因子
	
	$$
	\frac{\frac{ \partial M }{ \partial y } -\frac{ \partial N }{ \partial x } }{-M} = - \frac{3}{y}\implies \mu = \frac{1}{y^{3}}
	$$
	
	第二步：得到线性方程
	
	$$
	\frac{dx}{dy} = \frac{3}{y}\cdot x-y
	$$
	
## 常见积分形式配凑

!!! info
	
	$$
	\begin{gathered}
	ydx+xdy = d(xy) \\
	\frac{ydx-xdy}{y^{2}} = d\left( \frac{x}{y} \right)\\
	\frac{-ydx+xdy}{x^{2}+y^{2}} = d\left( \arctan \frac{y}{x} \right)\\
	\frac{ydx - xdy}{x^{2}+y^{2}} = d\left( \frac{1}{2}\ln | \frac{x-y}{x+y}| \right)
	\end{gathered}
	$$
